## 📌 Featured Projects

### 🧠 Second Sight
A personal "second brain" that turns pinned Claude.ai conversations into a categorized, interlinked Obsidian knowledge base — with a manifest-based caching layer and a spaced-repetition review dashboard.
🔗 [GitHub](https://github.com/sudenall/second-sight) · 🌐 [Web app](https://second-sight.sudedev.workers.dev/)

### ⚖️ Verdict Mesh
A resilient claim-verification architecture: four independent source-agents queried in parallel, coalesced through a weighted decision matrix, instead of trusting one unretried source. Hallucination rate dropped from ~12% to 0% against a naive single-source verifier on the same labeled claim set.
🔗 [GitHub](https://github.com/sudenall/verdict-mesh) · 🎮 [Live Demo](https://sudenall.github.io/verdict-mesh/)

### 🔍 Lost in the Middle vs. Hoisting
A real (not simulated) benchmark of the "lost in the middle" context-retrieval problem against live Claude API calls, with a typed error-handling layer (TransientError vs. FatalError) and retry/backoff logic.
🔗 [GitHub](https://github.com/sudenall/lost-in-the-middle) · 🎮 [Live Demo](https://sudenall.github.io/lost-in-the-middle/)

### 🧩 Resilient Context Orchestrator
A multi-agent orchestration simulator (search → retrieval → summarization → synthesis) with a per-agent circuit breaker and a compression step that routes token-budget overflow through summarization instead of naive truncation.
🔗 [GitHub](https://github.com/sudenall/intermediate-summaraziton-agent) · 🎮 [Live Demo](https://sudenall.github.io/intermediate-summaraziton-agent/)
